Piggy

A full-width web browser for iPhone.

Piggy is a WebKit-based web browser that gives web pages the whole width of the screen. Type any address or search in the address bar and browse any website, in normal or private tabs.

Features

  • Address bar that opens any website or searches with Google, DuckDuckGo, Bing or Naver
  • Tabs and private tabs, with optional Touch ID / Face ID lock for private tabs
  • Bookmarks and history, stored only on your device
  • Built-in content blocking for ads and trackers (EasyList / EasyPrivacy)
  • Compact toolbar while reading, so the page fills the screen
  • Two pages side by side on an unfolded iPhone
  • Downloads, find in page, text size, and desktop website mode
